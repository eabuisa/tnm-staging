Notes

Separate AJCC 8th chapter for HPV-mediated (p16-positive) oropharyngeal cancer. Extranodal extension (ENE) does NOT change the N category in p16-positive disease. There is no Tis category and no T4a/T4b split (T4 is a single category); stage IV is reserved for M1 disease only. Clinical and pathologic stage groups differ, and pathologic N is based on the number of positive nodes rather than size or laterality. Stage I is listed as T0-T2, N0-N1 following the NCI PDQ / NCCN tables; note T0 by definition occurs with a p16-positive neck node, so the T0N0 combination does not occur in practice. Parent T4 is the only T4 category and is used directly in the stage groups.

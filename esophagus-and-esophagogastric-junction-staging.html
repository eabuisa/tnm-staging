Notes

Stage groups in this file are for ADENOCARCINOMA only (stageGroups = clinical cTNM groups; stageGroupsPathologic = pathologic pTNM groups). Squamous cell carcinoma uses different clinical and pathologic stage-group tables and is not included; for squamous cell carcinoma, tumor grade and tumor location further modify the early pathologic stage groups. Postneoadjuvant (ypTNM) stage groups, which are the same for both histologies, are also not included. The T, N and M definitions are shared by both histologies. IMPORTANT: the pathologic adenocarcinoma groups for pT1-pT2 N0 M0 tumors depend on histologic grade, so pathologic staging asks for grade (the grade input is used only by the pathologic groups; the clinical groups do not use grade). Grade splits for node-negative tumors: pT1a N0 = IA if G1 or GX, IB if G2, IC if G3; pT1b N0 = IB if G1, G2 or GX, IC if G3; pT2 N0 = IC if G1-G2, IIA if G3 or GX. Adenocarcinomas whose epicenter extends no more than 2 cm into the gastric cardia are staged as esophageal cancers; those extending farther are staged as stomach cancers.

Reference only — staging must be confirmed against the full AJCC 8th edition chapter and the patient's complete clinical picture.
